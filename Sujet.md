# Chalenge éco-conception



Vous devez réaliser l'optimisation du site internet d'un apiculteur sur le plan accessibilité et éco-conception.

Pour ce faire vous pouvez utiliser les outils proposés par vos enseignants.



L'apiculteur désire gérer le contenu de son site lui-même d'où un espace administrateur.

L'accès se fait à partir de l'extension "/connexion" à l'url de base.

* login: admin
* mot de passe: 123456



L'apiculteur désires un Viewer de photo fonctionnel malgré le contexte écoconception.



Le site devra être hébergé.

Vous pouvez travailler en local avec Xampp et sa base de donnée MariaDB.



Une soutenance technique vous sera demandée au rendu du projet sous Moodle.
